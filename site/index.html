DeepSeek 海外邮箱登录启动器

自动识别你的系统与浏览器，给出对应的免下载启动方式。

在 Mac 上打开启动器

点击后「脚本编辑器」会自动载入脚本（本方式仅 Safari 可用）

  1. 点击上方按钮，Mac 弹出「脚本编辑器」并已载入启动脚本
  2. 按下 ⌘R（或点击 ▶︎ 运行）
  3. 确认弹窗后输入管理员密码（用于写入 /etc/hosts）
  4. Safari 自动打开 DeepSeek 登录页，显示邮箱 / Google 登录表单即成功
下载 launcher.applescript

若点击后浏览器直接显示文本，请右键链接 → 存储为 / 另存为

  1. 下载 launcher.applescript 后双击，会用「脚本编辑器」打开
  2. 按下 ⌘R（或点击 ▶︎ 运行）
  3. 确认弹窗后输入管理员密码（用于写入 /etc/hosts）
  4. Safari 自动打开 DeepSeek 登录页，显示邮箱 / Google 登录表单即成功
下载 launcher.bat

若点击后浏览器直接显示文本，请右键链接 → 目标另存为

  1. 下载 launcher.bat 到任意位置
  2. 右键该文件 → 以管理员身份运行（修改 hosts 需要）
  3. 脚本自动解析海外节点 IP、写入 hosts、检测已安装的浏览器并打开登录页
  4. 显示邮箱 / Google 登录表单即成功

下载后若被 SmartScreen 提示，选「仍要运行」；脚本内容为纯文本可自行审查。

当前设备无法运行启动器。本工具依赖 macOS 的「脚本编辑器」或 Windows 的批处理， 请在 Mac 或 Windows 电脑上访问本页（手机/iPad 不支持）。
前提条件：网络必须能把到海外节点的流量送到非中国大陆出口（专线分流、海外代理，或人就在海外）。 如果打开后仍是 +86 短信登录，说明当前网络不满足该条件。

还原

启动器会向 hosts 文件写入一行指向海外节点的记录（全系统生效）。测试完成后：

macOS 终端执行：

sudo sed -i '' '/platform.deepseek.com/d' /etc/hosts

Windows 用记事本（管理员）打开 C:\Windows\System32\drivers\etc\hosts，删除包含 platform.deepseek.com 的行。

手动方案（自动方式无效时）

macOS：复制脚本源码，在脚本编辑器中手动运行 
{{APPLESCRIPT_SOURCE}}

打开「脚本编辑器」（Spotlight 搜索 Script Editor）→ 粘贴 → ⌘S 保存为应用程序或直接在编辑器内 ⌘R 运行。

常见问题

脚本安全吗？

macOS 的 launcher.applescript 和 Windows 的 launcher.bat 源码完全公开（见仓库），只做三件事：解析 CloudFront 当前海外 IP、向 hosts 追加一行、打开浏览器登录页。没有任何数据上报，可逐行审查。

脚本编辑器打开是空的？

请确认是用 Safari 打开本页并点击按钮。旧版本页面使用了错误大小写的 applescript:// 地址会导致空白文档，当前版本已修复；若仍为空，请改用「下载 launcher.applescript」方式。

还是显示 +86 手机号登录？

说明请求到 DeepSeek 时用的仍是中国大陆出口 IP。检查网络是否具备海外出口；或重新运行一次启动器（CloudFront IP 可能已更换）。

页面提示 Request blocked / 403？

海外机房 IP 偶尔会被 AWS WAF 拦截，刷新重试即可；多次失败可稍后或换网络环境重试。

macOS 能不用管理员密码吗？

不能。修改 /etc/hosts 需要 root 权限，这是系统限制，脚本不存储任何密码。
