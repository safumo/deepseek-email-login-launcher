One-click launcher

Make DeepSeek show the email sign-in

Detects your OS and browser, points platform.deepseek.com at a CloudFront edge IP, and opens the sign-in page with the email / Google form instead of +86 SMS.

03常见问题

脚本安全吗？
macOS 的 launcher.applescript 和 Windows 的 launcher.bat 源码完全公开（见仓库），只做三件事：解析 CloudFront 当前海外 IP、向 hosts 追加一行、打开浏览器登录页。没有任何数据上报，可逐行审查。
脚本编辑器打开是空的？
请确认是用 Safari 打开本页并点击按钮；若仍为空，请改用「下载 launcher.applescript」方式。
还是显示 +86 手机号登录？
说明请求到达 DeepSeek 时仍使用中国大陆出口 IP。检查网络是否具备海外出口；或重新运行一次启动器（CloudFront IP 可能已更换）。
页面提示 Request blocked / 403？
海外机房 IP 偶尔会被 AWS WAF 拦截，刷新重试即可；多次失败可稍后或换网络环境重试。
macOS 能不用管理员密码吗？
不能。修改 /etc/hosts 需要 root 权限，这是系统限制；脚本不存储任何密码。
