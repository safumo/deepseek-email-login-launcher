DeepSeek 海外邮箱登录启动器

适用于 macOS + Safari。点击按钮即可在 Mac 的「脚本编辑器」中打开启动脚本，无需下载任何文件。

在 Mac 上打开启动器

需要在 Mac 上的 Safari / 默认浏览器中打开本页才能唤起

打开后怎么做

  1. 点击上方按钮，Mac 会弹出「脚本编辑器」，里面已载入启动脚本
  2. 按下 ⌘R（或点击工具栏的 ▶︎ 运行）
  3. 确认弹窗内容后，输入管理员密码（用于写入 /etc/hosts）
  4. Safari 自动打开 DeepSeek 登录页，显示邮箱 / Google 登录表单即成功
前提条件：网络必须能把到海外节点的流量送到非中国大陆出口（专线分流、海外代理，或人就在海外）。 如果打开后仍是 +86 短信登录，说明当前网络不满足该条件。

还原

脚本会向 /etc/hosts 写入一行指向海外节点的记录（全系统生效）。测试完成后在终端执行：

sudo sed -i '' '/platform.deepseek.com/d' /etc/hosts

手动方案（按钮无效时）

复制脚本源码，在脚本编辑器中手动运行 
{{APPLESCRIPT_SOURCE}}

打开「脚本编辑器」（Spotlight 搜索 Script Editor）→ 粘贴 → ⌘S 保存为应用程序或直接在编辑器内 ⌘R 运行。

常见问题

这个脚本安全吗？

脚本源码完全公开（见上方手动方案），只做三件事：解析 CloudFront 当前 IP、向 /etc/hosts 追加一行、打开 Safari 登录页。没有任何数据上报。你可以逐行审查后再运行。

还是显示 +86 手机号登录？

说明请求到 DeepSeek 时用的仍是中国大陆出口 IP。检查网络是否具备海外出口；或重新运行一次脚本（CloudFront IP 可能已更换）。

页面提示 Request blocked / 403？

海外机房 IP 偶尔会被 AWS WAF 拦截，刷新重试即可；多次失败可稍后或换网络环境重试。

能不用管理员密码吗？

不能。修改 /etc/hosts 需要 root 权限，这是 macOS 的系统限制，脚本本身不存储任何密码。
